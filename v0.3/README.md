# Linear Algebra C++ — v0.3

A lightweight, header-only C++ matrix library developed from scratch for learning and experimenting with linear algebra and computational physics.

> **Version:** v0.3  
> **Language:** C++  
> **License:** GNU General Public License v2.0 (GPL-2.0)

## Features

### Matrix operations

- Matrix creation with arbitrary row/column dimensions
- Element access with `operator()`
- Matrix addition
- Matrix subtraction
- Matrix multiplication
- Matrix transpose
- Matrix determinant
- Minor matrix calculation
- Matrix dimensions through `rows()` and `cols()`
- Stream output with `operator<<`
- Template-based implementation for different numeric types

## Example

```cpp
#include <iostream>
#include "Matrix.h"

int main() {
    Matrix<int> A(2, 2);

    A(0, 0) = 1;
    A(0, 1) = 2;
    A(1, 0) = 3;
    A(1, 1) = 4;

    Matrix<int> At = A.Trans();
    int determinant = A.Det();

    std::cout << "A:\n" << A << '\n';
    std::cout << "Transpose:\n" << At << '\n';
    std::cout << "Determinant: " << determinant << '\n';

    return 0;
}
```

The complete example is available in [`examples/main.cpp`](examples/main.cpp).

## Current API

| Function / Operator | Description |
|---|---|
| `Matrix<T>(rows, cols)` | Creates a matrix |
| `matrix(i, j)` | Accesses an element |
| `rows()` | Returns the number of rows |
| `cols()` | Returns the number of columns |
| `A + B` | Matrix addition |
| `A - B` | Matrix subtraction |
| `A * B` | Matrix multiplication |
| `A.Trans()` | Returns the transpose |
| `A.Det()` | Calculates the determinant |
| `A.Minor(i, j)` | Returns a minor matrix |
| `std::cout << A` | Prints the matrix |

## Header-only design

The library is currently implemented as a header-only library. To use it in another C++ project, add:

```cpp
#include "Matrix.h"
```

and make sure the `include` directory is included in the compiler's include paths.

For example:

```bash
g++ -std=c++11 -Iinclude examples/main.cpp -o matrix_example
```

## Determinant

The determinant implementation uses recursive minor expansion.

For example, for a 2×2 matrix:

```text
| a b |
| c d |
```

the determinant is:

```text
det(A) = ad - bc
```

The current implementation is intended for square matrices.
